- Stable 更新检查同时读取 GitHub Raw 稳定索引、GitHub Release API 和 `releases/latest` 兼容地址，并从所有 RSA 验签通过的清单中选择最高版本。

- 本机保存历史最高已验证 Stable 版本；远端返回更旧版本时提示缓存或同步异常，不再错误显示“当前版本已是最新版”。
- 更新日志会记录每个来源的版本或失败原因，以及最终采用的来源，方便对比不同电脑的更新结果。
- 正式发布完成资产校验后，流水线最后更新 `update-feed/stable.json` 并从 GitHub Raw 重新验证，确保新电脑可读取稳定索引。
