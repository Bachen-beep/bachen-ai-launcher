# 0.16.16

- 新增固定版本、大小和 SHA-256 校验的托管 Python 3.11.9 x64，同时保留 Python 3.12.10 x64。
- GitHub 仓库分析会读取 `project.requires-python`，从可用托管运行时中选择满足约束的最高版本；例如 `>=3.10,<3.12` 自动选择 Python 3.11.9。
- 自动分析安装和手动 GitHub 添加共用同一运行时选择逻辑，不再固定使用 Python 3.12.10。
- `uv sync` 和 `pip` 环境创建均显式使用选定的托管解释器，并完整校验上下限组合约束。
- 已有 `.venv` 版本不兼容或无法读取时会自动重建；重建失败会恢复旧环境，源码、模型权重、输出和令牌不受影响。
- Stable Audio 3 启动前会检查现有虚拟环境版本，必要时自动修复，并在安装界面显示项目约束和选定的托管 Python 版本。
