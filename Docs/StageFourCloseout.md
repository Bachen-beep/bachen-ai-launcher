# Stage Four Closeout

## Scope

Stage Four standardizes every launcher plugin through one manifest-shaped model. The built-in Woosh-DFlow, Stable Audio 3, and IndexTTS2 entries now use the same catalog fields as installable plugins.

## Completed

- Manifest v4 adds structured runtime and runtime version metadata.
- Package byte size is verified before SHA-256 verification and extraction.
- Preserved plugin-relative paths are declared by each manifest and used by source updates.
- Manifest validation covers SemVer, HTTPS package URLs, GitHub repository format, package size, ports, hashes, and safe relative paths.
- Existing signed v2 and v3 manifests remain compatible.
- All three built-in plugins are generated by `BuiltInPluginCatalog` instead of inline model definitions in the UI.
- Stable Audio 3 remains one plugin with three selectable launch profiles.
- Self-tests cover v4 signatures, size rejection, preservation metadata, v3 compatibility, and all three built-in definitions.

## Acceptance

Stage Four is complete when the Release build succeeds and `--self-test` reports all checks passed.
